**18650 battery health screener**

### 🏷️&nbsp; LMCC
**Product label compliance checker**

Upload a label, run a hybrid OCR scan, and get a compliance report you can export as PDF. Scan history is kept and editable, so verdicts can be corrected after the fact.

![Vercel](https://img.shields.io/badge/-Vercel-000?style=flat-square&logo=vercel&logoColor=white)
